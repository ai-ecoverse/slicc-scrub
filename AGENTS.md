# AGENTS.md

README.md is the spec; keep it exact. The design is §3.15 of secrets-tokens-design.md (rev 4) in slicc-agent-plan.

- Zero runtime dependencies, no DOM or Node APIs in src/, no eval or dynamic code, deterministic output.
- vectors.json is generated by `npm run vectors` (scripts/vectors.mjs) from how each input is built, never from the scrubber. Every consumer runs it.
- No comments in any file. Only README.md and AGENTS.md as docs.
- Unit tests live in the gitignored test/unit/ and must cover every changed line of src/.
- Integration tests in test/integration/ run the built dist/ against the vectors, every split point, and a fuzz test.
- `npm run lint`, `npm run build` and `npm test` must pass. Conventional commits.
